          #UnitRepeatBuildersActions

            1. Take a build into the game

            Select a run to export its plan.

            Download widget

            1. Send to BAR copies the widget to LuaUI/Widgets/ and the plan to LuaUI/Config/build_guide_plan.json in your BAR data folder. Sending another run replaces the plan.
            2. In game, enable Build Order Guide in the widget list (F11). Drag the panel by its title.
            3. If you send a new plan while BAR is running, type /luaui buildguide_reload.

            The panel shows the next steps, who builds them, the planned times and how far ahead or behind you are. It only displays; it never gives orders.

            2. Compare plan and game

            The widget writes LuaUI/Config/build_guide_log_<date>.json during each game.

              “Wait before” is how much later a step started than planned, compared with the step before: time spent walking or giving orders. Build times show whether the economy plan held: when they match, the economy did what the plan said and the remaining gap is execution.
